# Third-party components and data

The project license applies to Skarve's own material. Dependencies retain their
own licenses and attribution. The pinned inventory is
[third_party/DEPENDENCIES.json](third_party/DEPENDENCIES.json); complete retained
texts are under [third_party/notices](third_party/notices). This inventory is a
review of declared licenses and included notices, not a legal compatibility
guarantee or a determination of ownership.

| Category | Included or used | Distribution boundary |
|---|---|---|
| Rust dependencies | Locked Cargo graph for Linux x86-64, including build and test resolution | Source is fetched by Cargo. Compiled dependencies can be part of the native core; the inventory deliberately includes a superset. |
| Node FFI | Koffi 3.2.1 and its Linux x64 binary package | Bundled in the Node artifact. MIT notices include Koffi and its vendored Node API headers. |
| Native geospatial runtime | GDAL supplied by the operating system | Dynamically linked, not bundled. GDAL's own code is generally MIT; its components and linked system libraries have separate terms. |
| Python ordinary API | Python standard library, including ctypes | Python is installed by the user, not bundled. |
| Python typed buffers | NumPy, when using the NumPy convenience API | Optional, installed by the user. NumPy is BSD-3-Clause; its binary wheels may include other libraries and notices. |
| Build tools | Rust/Cargo, C compiler, Node/npm, Python build, setuptools and wheel | Development prerequisites, not bundled runtimes. |
| Tests and independent oracles | pytest, Hypothesis, NumPy, Rasterio, Shapely, SciPy, mpmath, affine | Installed development dependencies. GIS/scientific wheels can include additional native libraries under their own terms. |
| Data | Synthetic values, masks, grids and polygons generated by the included tests/examples | No external raster dataset, private application fixture or production asset is redistributed. |
| Optional exactextract backend | Pinned upstream C++ exactextract 0.3.0, unmodified, through an independently authored bridge | Source fetch is explicit and SHA-verified. An enabled native artifact statically links the upstream core; system GEOS/C++ runtime remain external. Its Apache-2.0 notice is retained. Disabled builds omit this backend. |
| Historical benchmark references | xagg, xESMF/ESMF, OCGIS and Raptor/Beast were studied separately | No implementation from these projects is bundled. Historical comparison does not transfer ownership or licensing. |

Cargo licenses include MIT, Apache-2.0, ISC, BSD-3-Clause, Unicode-3.0,
CDLA-Permissive-2.0 and declared alternatives. Some expressions contain `AND`
conditions, including ring's Apache-2.0 and ISC terms. They must not be reduced
to a blanket Apache label. The inventory preserves each declared expression and
all recovered notices rather than inventing a single license for the graph.

Six registry packages omit their license files: gdal, gdal-sys, geo, i_key_sort,
i_overlay and rstar. Their notices were recovered from the exact upstream Git
revisions recorded in each package's `.cargo_vcs_info.json`. The inventory
records those immutable URLs and hashes. Koffi's platform package uses the
parent Koffi MIT notice; the parent package's two vendored Node header notices
are retained as well. Packaging checks every recorded notice hash and refuses
an unreviewed dependency version or license expression.

GDAL's upstream guidance explicitly notes that its dependencies can have
different licensing terms. Consult the runtime packages' copyright records
when redistributing or changing that runtime; Skarve does not bundle or
relicense the operating system's GDAL dependency tree.
[GDAL licensing](https://gdal.org/en/stable/license.html).

The observed Ubuntu runtime includes GPL and LGPL components through GDAL.
The exact 107-library, 94-package development-host closure, package source
versions and distribution copyright records are in
[third_party/SYSTEM_RUNTIME.json](third_party/SYSTEM_RUNTIME.json).
[Runtime licensing boundaries](docs/RUNTIME_LICENSES.md) explains the review
scope and the separate binary-distribution decision. Installing libraries
externally does not by itself establish compatibility of a linked distribution.

The project license text is the unmodified
[Apache License, Version 2.0](https://www.apache.org/licenses/LICENSE-2.0.txt).
Preserve applicable copyright and license notices when redistributing source
or binary components, and follow each component's modification and attribution
requirements. Upstream names identify their components; no endorsement or
trademark grant is implied.
