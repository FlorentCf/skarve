# Changelog

## 0.1.1-alpha.1 (private launch candidate)

Adds a safe Rust consumer facade and packaged external examples alongside Python, Node.js/TypeScript and CLI. Curates an independent source history, brand assets, dependency/distribution checklist, public synthetic reproduction commands and the final native benchmark report. Closes test-helper, virtualenv, crate-membership and CI prerequisite integration gaps. No numerical kernel, reader, SKV format/writer or optional exactextract kernel changed in this launch pass.

The benchmark remains the frozen d15 runtime, not a timing claim about this rebuilt interface candidate. Apache-2.0 source release, branding and binary/registry distribution remain separate owner gates.

## 0.1.1-alpha.0 (frozen private milestone)

Adds the self-contained lossless SKV v0 serving format and installed conversion/query workflows. Retains direct TIFF/COG sources, optional preparation and explicit backend/numerical policies. Includes the accepted native-window, bounded boundary-coalescing, shared-mask and narrow median-reuse work. The finite native comparison and all losses are preserved under evaluation 741e528; this milestone is not overwritten by alpha.1.

## 0.1.0-beta.2

Adds the optional pinned exactextract 0.3.0 C++ backend through ordinary source
queries and finite many-zone/many-slice jobs. Explicit selection declares its
fractional calculation policy and Skarve-normalized source interpretation;
native strict remains the default. Embedded execution retains bounded source
windows, typed output ownership, cooperative cancellation and explicit errors
for unsupported isolation/statistics/index combinations.

Adds `Skarve`, `infuse`, `carve`, `ward` and `cleave` product names while retaining
existing API/CLI aliases. Python asynchronous source requests now drain repeated
cancellation and cannot cancel another request before acquiring native ownership.
Node continues using bounded asynchronous native execution. Includes focused
backend examples, declarations, contract tests, installation and source notices.

The beta.1 artifacts remain immutable. This candidate has a separate identity;
its benchmark report distinguishes native, delegated and caller-interface costs.

## 0.1.0-beta.1

First standalone release candidate: native-grid polygon statistics; local and
bounded remote source readers; retained source sessions and byte-bounded decoded
cache; optional persistent summaries with original-source boundaries; shared
multi-polygon/multi-slice jobs with bounded output pages; CLI, Python and Node
interfaces; version 1 typed-buffer ABI with strict and explicit ordered policies.

Includes thin-geometry and cancellation safeguards, source/index identity
validation, generated standalone examples, dependency notices and reproducible
comparative evidence. Linux x86-64 on the documented Ubuntu/GDAL runtime is the
initial binary qualification. The release report records the source-path
regression disposition and workloads where existing engines remain faster.

The implementation combines independently authored systems engineering with
established geometric and aggregation methods.
