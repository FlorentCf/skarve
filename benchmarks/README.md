# Skarve benchmarks

Start with the [final native Skarve + SKV report](native-skv/REPORT.md), [all observations and losses](native-skv/data/operations.csv), and [protocol/reproduction](native-skv/REPRODUCE.md). The measured runtime is d15b0bc; the launch consumer work is not silently substituted into those results.

Historical reports remain available for context: [beta2 optional-backend comparison](beta2/report/REPORT.md) and [beta1 standalone comparison](report/REPORT.md). Their controls, policies and builds differ; do not multiply or combine their speedups. `skv-v0/FINAL_MATRIX.md` and its tools preserve the earlier eight-lane tournament protocol. That is distinct from the completed seven-lane, 588-operation native freeze.

Benchmarks are evidence, not universal performance promises. Real raster pixels are not redistributed. Synthetic generators and saved-data checks run without application credentials. The public report retains losses, numerical differences and storage/build costs.
