# Optional backend: finite evaluation programme

This programme extends the existing generated-source benchmark. Beta1 files,
results and reports remain unchanged. It does not query external providers or
include private application material. Implementation and harness hashes are
frozen before a fresh evaluation seed is drawn. A smoke receipt is a functional
gate; final measurements run only in one exclusive serial timing lane.

The comparison has two numerical tracks. Native uses
`native_grid_planar_fractional` and is checked independently against exact
Fraction rectangles or GEOS cell intersections with `math.fsum`. Delegation
uses `exactextract_fractional_v030` over `skarve_normalized_f64_v1`: binary64
values after raw NoData/masks and scale/offset. Its independent natural Python
upstream control receives those same interpreted values and masks. Precision
differences from the strict oracle are retained separately from bridge defects.
Fractional support is never described as integer valid-cell count.

| Family | Fixed useful work | Complete controls and accounting |
|---|---|---|
| Single polygons | 100 distinct hot/scattered polygons; unscored cache fill separately charged | Native, delegated feature/raster, eligible auto and natural upstream feature/raster; registration, call, canonical five fields, close; p50/p95 over distinct queries |
| Shared batches | 8 and 64 polygons, including holes/multipart/slivers/partial/outside; one 24-band source and six distinct two-band files | Natural all-feature/all-band operations; native source-layout/fixed, delegated two strategies and eligible auto; five common fields and separate rich-output lane; three rounds with min/median/max |
| Reuse and preparation | The same mixed and large-interior polygons on one stable raster | Native original-source index versus direct/delegated controls; build/open/storage and observed cumulative cost; no extrapolated payoff presented as a measurement |
| Loopback remote | New geometries on a generated tiled GeoTIFF; first, nearby, scattered and revisit queries | Bounded server request/body logs plus native cache/decoded counters establish actual hits/evictions; mutation rejection; no cloud claim |
| Bridge overhead | Identical normalized arrays, all zones/bands | Same-build independent upstream C++ ArraySource/MapWriter versus the typed bridge, separate from installed file calls; nested processor and callback clocks are nonadditive. Python upstream supplies a separately built correctness control. |
| Isolation | The same public generated jobs through the older private worker | Startup, snapshot/file registration, call, canonical output and close charged. The private adapter is not exported or relabelled as the native bridge. |
| Calibration/eligibility | Dyadic and decimal coverage, severe signed cancellation, tiny positive cells, masks, scale/offset, empties, holes and multipart | Exact Fraction and pinned upstream controls; explicit policy/resource/unavailable errors; finite output cardinality and source identity checks |

Sources are eight 512×512 synthetic TIFFs generated by the existing harness,
with signed dyadic Float32 values and band-specific NoData. Main timing fixtures
use identity scale/offset, so natural file adapters interpret the same values;
nonidentity metadata is probed separately with normalized controls. The
reference receives all bands naturally even where native registration uses
bounded groups. No per-polygon process or JSON pixel transport is introduced.

Resource controls start at one upstream/native thread, 64 MiB GDAL cache,
explicit native decoded cache states and a 2 GiB process address-space guard.
All native/EE/auto batch jobs explicitly use a 1 GiB working budget. This
allows the conservative per-slice reader admission for the 24 distinct date
slices; those identities are not collapsed into a single synthetic slice to
fit the ordinary 512 MiB default. The Python upstream and historical worker
have their separately documented process/cache controls, rather than an
invented equivalent internal working-budget API.
The batch contribution admission budget is the normal 1,000,000,000 default;
the largest requested full-grid upper bound is 512×512×24×64 = 402,653,184.
This bound is admission work, not a measured count of visited cells. Every
delegated strategy uses `max_cells_in_memory=1,000,000` except auto, whose
resolved defaults and provenance are recorded rather than silently rewritten.
Embedded cancellation is cooperative; an upstream chunk/window setting is not
a hard RSS bound. Hard-isolation requests are ineligible for embedded execution.
Peak RSS and actual window/copy counters are retained where exposed; missing
counters remain unavailable. Separately observed process peaks are not summed
and called synchronized memory usage.

Native compact numeric output is a supplemental six-statistic control because
its established schema requires integer count. Paired native/EE full-output
lanes at both batch sizes request exactly the same five statistics; complete
returned metadata and projection costs are charged. The retained first smoke
and [cropped NumPy reference finding](REFERENCE_VALIDITY.md) explain the finite
harness corrections before final evaluation, without changing engine behavior.

The report will have six or seven supported chart families and one summary
image, exported as SVG/PNG plus HTML, Markdown and raw CSV/JSON. Absolute bars
start at zero; ratios name their numerator and denominator. Three batch repeats
show observed spread, not confidence intervals or a stable p95. Any fastest
strategy selected after measurement is labelled as such, and every alternative,
loss, incompatible result and error remains inspectable. Unsupported methods
have no fabricated bars. There is no application adoption or novelty claim.

Primary API contract: [exactextract Python API](https://isciences.github.io/exactextract/exactextract.html).
Pinned reduction behavior: [v0.3.0 raster statistics](https://github.com/isciences/exactextract/blob/v0.3.0/src/raster_stats.h).
The independent control is the same pinned upstream release, not a second
competitor. Its source license does not decide linked-runtime redistribution.
